Page builders, SEO, SMTP, cache, WooCommerce, Easy Digital Downloads, and backups for OneMCP.

== Description ==

OneMCP Pro is an add-on. Install and activate OneMCP first.

Pro adds these abilities. The free plugin keeps the MCP server and WordPress core tools.

* Page builders: Pagelayer, Elementor, SeedProd, Divi, Bricks, Beaver Builder, and Breakdance.
* SEO: SiteSEO, Yoast SEO, Rank Math, All in One SEO, and SEOPress.
* SMTP: GoSMTP, WP Mail SMTP, FluentSMTP, Easy WP SMTP, Post SMTP, and SMTP Mailer.
* Cache: SpeedyCache, LiteSpeed Cache, WP Rocket, WP Super Cache, W3 Total Cache, WP Fastest Cache, WP-Optimize, and SiteGround Optimizer.
* WooCommerce: products, variations, orders, customers, coupons, reviews, and refunds.
* Easy Digital Downloads: downloads, orders, discounts, access, licenses, and subscriptions.
* Backups: Backuply and Duplicator.
* Activity log retention of 2,000 entries and CSV export.
* License key and plugin updates from https://a.softaculous.com/onemcp.

Pro classes live in the OneMCPPro namespace and load through that plugin's autoloader.
